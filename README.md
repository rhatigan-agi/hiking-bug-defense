# New England Bug Doctrine

A layered, seasonal field manual for hiking New England without getting eaten — ticks, black flies, mosquitoes, deer flies and salt-marsh greenheads, each with a different countermeasure.

**Read it:** [index.html](index.html) — a single self-contained page. Enable GitHub Pages on this repo and it publishes as-is.

## What this is

Most bug guides are about what to wear while walking. That's about half the problem. This one is organized around three ideas:

1. **The misery lives in three moments** the usual advice ignores — the stop (lunch, the summit), the bad twenty minutes (the black fly cloud), and the aftermath (a week of itching).
2. **Countermeasures differ by insect, not by body part.** Head-to-toe organization is the common structural mistake — ticks, black flies and greenheads need genuinely different answers.
3. **New England is five bug regions, not one.** The North Woods, the mountains, southern New England, the salt marsh coast, and the islands each need a different kit.

It also carries a **skip list** — widely repeated advice (vanilla extract on the ears, repellent oil on a hat brim, mirrored lenses) that doesn't survive contact with the evidence, with the reasoning for each.
